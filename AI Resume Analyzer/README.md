Overview

The AI Resume Analyzer is a Python-based application designed to automate job searching by analyzing user resumes, extracting key skills, and matching them with relevant job listings from online sources.
It eliminates the need for manual searching and provides personalized job recommendations within seconds.

The system processes a resume, identifies important keywords, queries an API for job postings, calculates match and relevance scores, and displays results through a clean user interface.

Features

    -Automated resume parsing to extract skills, experience, and keywords
    -API integration for retrieving real-time job listings
    -Match & relevance scoring for ranking job opportunities
    -Interactive UI that allows expanding job details and navigating results
    -Direct apply links to the employer or LinkedIn
    -Fast, efficient workflow from resume upload to job suggestions

Installation
Requirements:

    -Python 3.8+

    -requests (for API calls)

    -tkinter or chosen UI framework

    -Any additional packages for parsing (e.g., spacy, pdfminer, etc.)

Setup:

    git clone https://github.com/yourusername/ai-resume-analyzer.git
    cd ai-resume-analyzer
    pip install -r requirements.txt

Running the Application:

    *bash*
    python Main.py

Usage

    Launch the application
    Click Upload Resume
    Allow the system to parse and analyze
    View job matches with scores
    Expand details with the “+” button
    Use Apply links to visit postings online
